---
title: 基础配置
description: 配置 NextDoc4j 的核心开关、文档入口、跨域调试和生产环境安全模式。
---

所有配置均使用 `nextdoc4j` 命名空间。

## 参数速查

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `nextdoc4j.enabled` | `boolean` | `false` | 是否启用 NextDoc4j。 |
| `nextdoc4j.doc-path` | `string` | `/doc.html` | 自定义文档入口，使用以 `/` 开头的单段路径。 |
| `nextdoc4j.cors` | `boolean` | `false` | 是否允许前后端分离项目跨域联调。 |
| `nextdoc4j.production` | `boolean` | `false` | 生产环境安全隐身模式，关闭文档和原始 SpringDoc 元数据暴露。 |

## YAML 配置

```yaml title="application.yml"
nextdoc4j:
  enabled: true
  doc-path: /doc.html
  cors: false
  production: false
```

## Properties 配置

```properties title="application.properties"
nextdoc4j.enabled=true
nextdoc4j.doc-path=/doc.html
nextdoc4j.cors=false
nextdoc4j.production=false
```

## 多环境配置

开发环境可以开启跨域和文档，生产环境建议启用安全隐身：

```yaml title="application-prod.yml"
nextdoc4j:
  enabled: true
  production: true
```

`production=true` 会同时隐藏 NextDoc4j 文档入口和 SpringDoc 原始接口描述，适合由独立网关或发布流程控制文档暴露。

## 配置注意事项

- `doc-path` 必须是单段路径，例如 `/docs`；非法格式会在启动时快速失败。
- 修改文档入口后，网关路由、反向代理和部署说明需要同步更新。
- 关闭 `enabled` 后不会注册相关路由和自动配置 Bean。
