NextDoc4j 是面向 SpringDoc 和 OpenAPI 3 的现代化接口文档与在线调试工作台。

## 推荐阅读路径

1. [快速开始](/guide/start/started)：完成依赖引入、配置和首次访问。
2. [基础配置](/guide/config/basicconfiguration)：了解文档入口、跨域和生产模式。
3. [界面功能总览](/guide/ui/overview)：熟悉浏览、调试、搜索和导出能力。
4. [网关聚合插件](/guide/plugin/gateway)：接入 Spring Cloud Gateway 微服务文档。

## 能力范围

- Spring Boot 3 / 4、WebMvc / WebFlux 统一 Starter。
- Spring Cloud Gateway WebFlux / WebMvc 网关聚合。
- OpenAPI 分组、接口详情、模型和请求响应示例浏览。
- 在线调试、认证管理、SSE 流式响应和多格式导出。
- 枚举、认证、Sa-Token 和 Markdown 文档扩展。
