右上角“偏好设置”抽屉包含“通用偏好”和“Nextdoc4j”两个页签。修改后自动保存到当前浏览器，界面习惯与服务的业务配置各自独立。

## 通用偏好

<ThemedScreenshot light="/images/screenshots/features/preferences-light.webp" dark="/images/screenshots/features/preferences-dark.webp" alt="通用偏好抽屉中的主题、内容宽度、水印、版权与标签和菜单设置" width={432} height={805} />

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 主题模式 | 跟随系统 | 可固定浅色 / 深色，或随系统切换 |
| 内容宽度 | 标准 | 在自适应、标准与宽屏之间选择 |
| 显示水印 | 关闭 | 按个人阅读习惯控制工作台水印 |
| 显示版权 | 开启 | 宿主提供自定义版权内容时可控制展示 |
| 鼠标中键关闭标签页 | 开启 | 用中键快速关闭普通标签 |
| 恢复上次标签页 | 开启 | 再次进入时恢复保存的工作区 |
| 菜单展开方式 | 自由展开 | 可切换为单分组展开 |

### 主题与内容宽度

固定主题优先于系统主题；选择“跟随系统”后，操作系统配色变化会同步影响工作台。顶部主题按钮也提供快速入口。

内容宽度影响阅读工作区，不会改变接口参数或请求数据。宽屏适合同时查看较大的结构和示例；窄屏时，页面会按可用空间调整布局。

### 菜单与标签

自由展开适合并排寻找多个分类，单分组模式适合减少长目录。标签支持固定、拖动、关闭与批量管理；固定标签不会按普通可关闭标签一样被批量清理。

“恢复上次标签页”保存的是工作上下文，并不保证上一次的服务响应、文件选择和所有临时变量也一并恢复。

## Nextdoc4j 页签

这个页签展示运行模式、服务情况、接口分组数与调试草稿数量，并提供文档与调试行为开关。

<ThemedScreenshot light="/images/screenshots/features/cache-settings-light.webp" dark="/images/screenshots/features/cache-settings-dark.webp" alt="网关模式的 Nextdoc4j 偏好页签，包含生效范围、分组概览与调试草稿管理" width={432} height={805} />

| 设置 / 信息 | 默认与用途 |
| --- | --- |
| 运行环境 | 区分单体应用与网关聚合，查看文档服务的可用情况 |
| 设置生效范围 | 网关中可选择全部服务或当前服务 |
| 接口分组概览 | 默认开启，控制点击分类时的概览体验 |
| 调试草稿缓存 | 默认开启，控制调试输入的保存行为 |
| 缓存状态 | 查看当前范围的草稿数量，按需清理 |

网关选择“全部服务”时，相关开关针对多个服务应用；选择“当前服务”时只处理当前范围。清理之前先确认范围，避免把暂时不用的服务草稿一起删除。

## 哪些内容会保留

| 数据 | 保存范围 / 生命周期 | 刷新后的预期 |
| --- | --- | --- |
| 通用偏好 | 当前浏览器 | 保留主题、宽度和界面习惯 |
| 标签与接口页面状态 | 当前应用 / 服务 | 在开启恢复时尽可能回到原工作上下文 |
| 调试参数、Body、普通覆盖 | 缓存开启时，按服务、接口与 Body 类型保存 | 可恢复相应草稿 |
| 前后置步骤配置 | 与当前接口调试配置关联 | 可恢复步骤与脚本配置 |
| 认证凭据 | 默认在当前标签页会话中，按服务区分 | 刷新同一会话可继续使用；关闭会话后不保证保留 |
| Cookie 与认证值的单次覆盖 | 当前标签页会话，不作为普通持久化参数值保存 | 还受浏览器会话与凭据状态影响 |
| 已选文件 | 当前页面内存 | 需要重新选择 |
| 流程变量与辅助步骤结果 | 当前服务的内存会话 | 刷新后清除 |
| 实时响应与 SSE 历史 | 当前调试过程中的展示数据 | 不应作为永久调用日志使用 |

调试草稿会过滤已知的敏感请求头，Cookie 和文件本体不作为普通草稿写入。但 Body、Query 或自定义普通字段仍是你填写的内容，应按工作需要决定是否启用缓存。

## 关闭缓存、清理草稿、恢复默认

这三个操作解决不同问题：

| 操作 | 作用 |
| --- | --- |
| 关闭调试草稿缓存 | 改变后续调试草稿的保存行为 |
| 清理草稿 | 删除所选范围已保存的调试草稿与相关覆盖，按确认提示执行 |
| 恢复默认偏好 | 把界面和行为偏好恢复为默认值，不等于清空所有本地数据 |

需要重新演练一个接口时，可以先使用调试页的“恢复接口示例”；需要清理一个服务积累的草稿时，再使用偏好设置中的范围清理。

全局认证和公共参数有独立入口。清理调试草稿不能代替“清除全部凭据”，恢复默认偏好也不会让后端业务数据恢复到演示初始状态。

## 本地数据异常时如何定位

| 现象 | 优先检查 |
| --- | --- |
| 主题总与系统不同 | 是否显式选了浅色或深色 |
| 再次打开没有恢复标签 | 恢复开关、浏览器站点数据与当前服务范围 |
| 参数没有恢复 | 草稿缓存开关、接口方法 / 路径、Body 模式和是否清理过 |
| 刷新后附件消失 | 文件只保留在内存，这是预期行为 |
| 换服务后变量为空 | 流程变量按服务隔离，刷新也会清空 |
| 无痕窗口与普通窗口设置不同 | 浏览器存储与会话范围不同 |
| 设置无法保存 | 检查浏览器是否限制站点存储，以及当前站点是否发生变化 |
