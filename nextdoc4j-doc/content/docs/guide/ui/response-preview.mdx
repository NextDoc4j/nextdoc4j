发起在线请求后，结果区域会同时提供响应内容、HTTP 状态、耗时、大小、头信息和实际请求。先看状态与内容类型，再选择合适的阅读方式。

## JSON 响应与字段说明

JSON 返回支持格式化 / 原始切换、结构折叠、字段说明、枚举含义、搜索、复制和下载。字段注释来自接口的响应 Schema，真实值来自这次请求。

<ThemedScreenshot light="/images/screenshots/features/response-json-light.webp" dark="/images/screenshots/features/response-json-dark.webp" alt="用户查询的 JSON 实时响应，包含状态码、耗时、大小与字段说明" width={560} height={650} />

| 操作 | 作用 |
| --- | --- |
| 格式化 | 按结构阅读 JSON 等支持的内容，展开或折叠层级 |
| 原始 | 检查接收的原始文本表示 |
| 字段说明开关 | 减少注释干扰，或对照 Schema 理解字段与枚举 |
| 查找字段或值 | 在当前可展示内容中定位文本 |
| 复制 / 下载响应 | 带走响应内容，便于复现或反馈 |

字段被省略、响应结构与文档不一致或没有可匹配的 Schema 时，不能期待每个返回字段都有注释。JSON 解析失败也可能回退为文本展示，应同时检查响应 Content-Type 与正文。

## 不同内容类型的处理

| 返回内容 | 当前阅读方式 | 单体 Demo 中可体验的接口 |
| --- | --- | --- |
| JSON | 结构化格式化、原始文本、字段与枚举说明 | 用户查询、系统信息 |
| XML | 按 XML 内容格式化或查看原文 | 获取系统配置 - xml |
| 纯文本 | 文本预览、查找、复制与下载 | 获取系统配置 - 纯文本 |
| CSV | 文本方式阅读与下载 | 导出系统配置 - CSV |
| HTML | 作为内容文本检查，不作为任意网页执行 | 系统信息 - HTML 视图 |
| 图片 / 二进制附件 | 按 Blob 处理并自动下载，结果区显示下载提示 | 用户头像原始二进制、下载系统日志 |
| JSON / 文本中的 Base64 图片 | 识别可支持的图片数据，进入图片预览 | 用户头像、系统二维码、相册缩略图 |
| SSE | 持续接收事件，按事件列表或原始内容阅读 | SSE 测试分组 |

响应展示以实际媒体类型和正文为依据。`Content-Disposition: attachment` 会使内容按附件处理；空正文响应会提示请求已完成但没有响应正文，不应当作加载失败。

## Base64 图片预览

当 JSON 字段中包含可识别的图片数据时，可以通过图片入口查看图片，结合字段路径定位来源。相册数组和嵌套对象中的图片，也可以按识别结果逐项查看。

<ThemedScreenshot light="/images/screenshots/features/response-image-light.webp" dark="/images/screenshots/features/response-image-dark.webp" alt="头像接口返回 Base64 数据后的图片查看入口与响应内容" width={660} height={472} />

图片预览适合核对头像、二维码等内容。不能把任意 Base64 文本都当成图片；原始二进制附件与 JSON 中的图片字段也属于不同响应形式。

## SSE 流式事件

在[AI 逐字流 SSE](https://single-demo.nextdoc4j.top/#/docs/operations/streamTokens/debug)等接口中，点击发送后不必等待连接结束，事件会随到达逐步呈现。

<ThemedScreenshot light="/images/screenshots/features/response-sse-light.webp" dark="/images/screenshots/features/response-sse-dark.webp" alt="SSE 实时响应列表展示已接收的事件及消息内容" width={560} height={690} />

| 事件信息 | 含义 |
| --- | --- |
| 顺序与到达时间 | 帮助区分每条消息和观察接收过程 |
| `event` | 服务端指定的事件类型；缺省按 `message` 处理 |
| `id` | 服务端提供时显示的事件标识 |
| `data` | 合并多行 data 后的消息；JSON 数据可进一步按结构阅读 |
| 已省略条数 | 持续输出较大时提示旧消息已经从保留列表移除 |

支持切换原始内容、搜索消息、复制和下载，并可手动终止接收。请求超时限制建立响应前的等待；进入 SSE 接收后，工作台清除该等待计时，不会仅因持续推送超过这个时长就自动终止。持续没有消息时还要检查代理缓冲与服务端推送行为。

### 长流的保留范围

当前事件缓冲同时限制最多 500 条事件和约 2 MiB 的序列化历史。超出后会淘汰较早消息并给出提示；复制与下载只包含保留的内容，大小指标反映累计事件文本大小。

这是一段联调接收窗口，不是持久化消息存档；终止接收也不会自动向服务端发送一项业务撤销操作。

## 大响应不会全部塞进可视区域

较大的响应会使用受限预览，当前阈值为正文超过 1 MiB，预览前 256 KiB，并明确提示搜索只覆盖预览部分。

| 能力 | 大响应时的范围 |
| --- | --- |
| 展示 / 文本搜索 | 受限预览 |
| 复制 / 下载 | 完整响应内容 |
| 后置操作 | 完整数据 |
| 图片扫描 | 可以通过显式入口扫描完整响应中的图片 |
| JSON 格式化 | 通过格式化预览入口按需处理 |

因此，“预览里没找到字段”不等于服务器没有返回该字段。优先下载完整响应或通过后置操作确认需要的数据。

## 头信息、耗时与大小

头信息页区分“应用配置”的请求头和“浏览器可读”的响应头。Host、Origin、Cookie、Content-Length 等最终发送值由浏览器参与管理；跨域响应头受 `Access-Control-Expose-Headers` 限制，`Set-Cookie` 不向脚本开放。

耗时和大小旁可查看明细，用于区分等待、读取和数据体积。它们是浏览器当前请求可获得的指标，不等同于服务器端方法耗时或链路追踪结果。
