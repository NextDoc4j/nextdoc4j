聚焦 Spring Cloud Gateway 微服务网关场景下的前端体验：服务动态选择、接口上下文隔离与全链路跨服务导出。

## 1. 服务选择与菜单隔离

![微服务网关服务选择器](/images/screenshots/guide/gateway-plugin-ui.png)

- **智能感知网关模式**：当检测到网关聚合模式时，工作台顶部导航栏自动激活「服务选择器」组件。
- **服务维度完全隔离**：切换微服务（如 `user-service` 到 `order-service`）时，左侧接口菜单与详情数据即时重载隔离。
- **统一单点入口**：微服务团队只需维护网关单点访问地址（如 `http://gateway:9000/doc.html`）。

## 2. 聚合模式下的全局调试与检索

- **跨服务全局搜索**：全局搜索框支持同时索引所有下游微服务的 API 路由与说明。
- **服务路由自动修正**：在线调试时，网关前缀与目标微服务 Context-Path 自动对齐重写。
- **状态自动记忆**：浏览器刷新后自动停留在上次选中的微服务及接口，开发体验不中断。

## 3. 微服务聚合多格式导出

- 支持按特定下游微服务独立导出，或全量聚合导出。
- 支持 Markdown、HTML、OpenAPI JSON、Word `docx` 与 PDF 文档格式。
