## 服务切换会改变什么

1. 打开顶部“当前服务”，选择可用服务；也可以点击主页节点切换。
2. 工作台加载该服务的 OpenAPI 文档、接口分类、模型和附加说明。
3. 查看接口后进入调试，请求路径会结合当前服务的聚合与路由信息生成。
4. 切回原服务，继续使用该服务自己的工作区与配置。

| 跟随服务变化 | 说明 |
| --- | --- |
| 接口列表和模型 | 属于当前服务的文档内容，不把所有服务混成同一份菜单 |
| SpringDoc 分组 | 属于服务内部的文档组织，和顶部的服务选择不同 |
| 标签页与接口状态 | 按服务范围保留，避免同名接口互相覆盖 |
| 调试草稿和流程变量 | 分别按服务隔离，并各自遵循持久化 / 内存规则 |
| 服务级认证与公共参数 | 使用当前服务配置，再结合适用的网关默认值 |

例如“用户管理”服务内仍可能有多个 SpringDoc 分组。先选服务，再在左侧选分组，可以避免把“切服务”和“切文档”混淆。

## 节点状态代表什么

主页展示服务名称、文档地址与 UP / DOWN 等状态，帮助判断当前能否加载该服务的文档。在线演示中的节点和状态会随部署调整。

| 现象 | 理解与处理 |
| --- | --- |
| 某个节点 DOWN | 优先检查该节点的 OpenAPI 地址、路由和文档认证；其他可用服务仍可继续浏览 |
| 已加载文档，但业务请求失败 | 文档可达和业务接口可调用是两件事，继续检查请求地址与业务响应 |
| 服务选择器里缺少服务 | 先核对后端服务发现 / 静态路由配置，再查看聚合返回数据 |
| 某服务模型和接口数量不同 | 当前指标跟随加载文档，不是整个集群所有接口的运行统计 |

工作台展示文档加载视角的状态，不能替代注册中心或运维平台的完整健康检查。

## 调试地址如何核对

网关可能增加路由前缀，也可能在转发时移除一段路径。NextDoc4j 根据聚合信息、服务文档和请求前缀构建调试地址，但最终仍需要网关的路由与代理规则配合。

| 地址组成 | 用途 |
| --- | --- |
| 官网或工作台 URL | 打开文档界面的位置 |
| 服务 OpenAPI URL | 获取该服务规范，例如 Demo 的 `/system/v3/api-docs` |
| 接口 Path | 规范中的业务路径，例如 `/api/system/info` |
| 实际调试 URL | 结合服务选择、文档服务器和网关前缀得出的最终请求地址 |

调试返回 404 时，先到“实际请求”复制最终 URL，检查前缀有没有漏加或重复。不要把获取 OpenAPI 的地址直接当作业务 API 的统一前缀。

后端接入与路由行为见[网关聚合插件](/guide/plugin/gateway)，UI 入口与 OpenAPI 地址的区别见[基础配置](/guide/config/basicconfiguration)。

## 配置到底影响哪个范围

| 能力 | 配置范围 |
| --- | --- |
| 外观主题、内容宽度等通用偏好 | 当前浏览器的工作台偏好 |
| 公共 Header / Query | 网关全局默认 + 当前服务继承与覆盖 |
| 认证凭据 | 当前方案与当前服务范围；不自动等于所有服务共享 |
| 调试参数与 Body | 当前服务、接口与相应 Body 模式 |
| 流程变量 | 当前服务的内存会话，刷新清除 |
| 分组概览 / 草稿缓存开关 | 在偏好设置中选择当前服务或全部服务 |

“全局参数”的全局与“全局搜索”的全局描述不同操作范围，应以各自页面的范围选择器为准。

## 跨服务搜索

全局搜索可以在后台索引多个服务文档，并提供服务筛选。结果会标出所属服务，选择远程结果后进入相应服务中的接口或模型。

某个文档加载失败时，搜索会提示部分服务未能加入索引。看不到结果时应先检查索引状态和服务范围，不能把“没有结果”直接解释为集群里没有该接口。

搜索字段、类型与快捷键见[搜索与文档导出](/guide/ui/search-export)。

## 聚合导出

文档下载页在网关模式下提供三个范围：

| 范围 | 适合的用途 |
| --- | --- |
| 全部微服务 | 给整个集群生成一份资料 |
| 按微服务选择 | 只交付某几个服务 |
| 跨服务细选 | 从多个服务分别勾选需要的接口 |

导出前检查已选服务、接口数量和预览；有服务加载失败时，先阅读提示再决定是否交付当前可用范围。生成的资料以本次成功取得并选中的文档为准。

## 分享服务内的接口

网关 Hash 地址包含服务标识，例如：

```text
https://gateway-demo.nextdoc4j.top/#/services/系统管理/home
```

分享接口时直接复制浏览器完整 URL，浏览器会处理中文路径编码。接收者打开后仍受服务可达性、文档访问认证与业务权限限制，链接不会携带你的本地 Token 和草稿。
