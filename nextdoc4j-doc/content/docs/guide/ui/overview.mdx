工作台把接口说明、请求调试、数据模型和文档管理放在同一个入口。可以先在[单体演示](https://single-demo.nextdoc4j.top/)熟悉操作，再到[网关演示](https://gateway-demo.nextdoc4j.top/)体验多服务切换。

## 先认识四个区域

| 区域 | 可以做什么 | 使用提示 |
| --- | --- | --- |
| 左侧导航 | 在主页、文档管理、接口文档、实体模型和其他文档之间切换 | 点击箭头展开目录，点击条目打开页面；窄屏下通过侧栏开关访问 |
| 顶部标签栏 | 同时保留多个接口、模型或管理页面 | 标签显示接口方法与名称，方便在相关页面间来回查看 |
| 右上角工具 | 全局搜索、主题切换、偏好设置 | 搜索适合跨分组定位；偏好设置控制当前浏览器的界面习惯 |
| 中间工作区 | 项目概览、接口详情或调试面板 | 页面会随当前文档、分组和网关服务变化 |

## 项目概览能告诉你什么

主页读取当前 OpenAPI 的标题、版本、描述、服务地址、联系人与协议。API 服务基址支持点击复制，联系人和项目主页按文档声明展示。

| 指标 | 含义 |
| --- | --- |
| API 端点 | 当前文档中的接口操作数量；同一路径的 GET 与 POST 是不同操作 |
| 实体数据模型 | 当前文档声明的数据结构与枚举引用 |
| 分类标签分组 | 接口在文档中的业务分组 |
| 请求方法分布 | GET、POST、PUT、PATCH、DELETE 等方法的数量和比例 |
| 安全认证策略 / 微服务集群 | 单体侧重认证声明；聚合场景展示服务数量与可用状态 |

指标会随 Demo 与服务版本变化。它们描述文档结构，不能代替接口运行成功率或服务性能监控。

## 分组、标签与接口导航

左侧“接口文档”既可以展示全部接口，也可以按 SpringDoc 分组浏览。分组内部再按 Tag 组织接口，HTTP 方法徽标用于区分同名接口。

- **SpringDoc 分组**：决定加载和浏览哪一份接口文档。
- **Tag 分类**：帮助你在文档内按业务域寻找接口。
- **分组概览**：启用后，点击分类可先查看该分类下的接口集合，再进入详情。
- **实体模型**：从数据结构出发查看字段，不需要先找到引用它的某个接口。

菜单展开方式可在偏好设置中选择“自由展开”或“单分组”；分组概览开关位于偏好设置的 Nextdoc4j 页签。

## 用标签页保留工作上下文

打开接口、切换调试、查看模型时，顶部标签栏保留相应页面。支持拖动调整标签顺序，也可以通过标签菜单执行关闭、批量关闭、新窗口打开等操作。

| 操作 | 作用 |
| --- | --- |
| 点击标签 | 回到已打开的页面 |
| 拖动标签 | 将常用接口按工作顺序排列 |
| 点击关闭 / 鼠标中键 | 关闭标签；中键行为可以在偏好设置中关闭 |
| 标签上下文菜单 | 管理当前与其他标签，或在新窗口中打开 |
| 恢复上次标签页 | 刷新后恢复工作区；由偏好设置控制 |

接口详情和在线调试都有可分享的 Hash 地址。网关地址还包含服务标识，分享时复制完整浏览器 URL，接收者仍需具有相应文档和接口访问权限。

## 推荐的第一次体验

1. 从主页进入“接口文档”，打开用户管理中的“根据 ID 查询用户”。
2. 阅读参数与响应结构，再点击“在线调试”，填写 `id=1` 发起查询。
3. 查看“实时响应”“头信息”“实际请求”，对照接口说明理解真实请求。
4. 打开“更新用户”体验 JSON 枚举选择，最后到“文档下载”选择导出范围。

需要先接入自己的服务，见[快速开始](/guide/start/started)；需要改变后端行为，见[配置说明](/guide/config/basicconfiguration)。
