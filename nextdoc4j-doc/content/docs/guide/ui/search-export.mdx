搜索用于快速找到正在工作的内容，导出用于把选定的接口规范交给其他人。两个入口都能按范围缩小内容，网关模式还支持跨服务操作。

## 打开全局搜索

点击顶部搜索按钮，或使用 **macOS `⌘ K` / Windows、Linux `Ctrl K`**。输入后可切换全部、接口、模型和文档类型；网关模式还有服务筛选。

## 搜索范围与写法

| 类型 | 实际索引内容 | 可以尝试 |
| --- | --- | --- |
| 接口 | 路径、名称、operationId、接口说明、Tag | `/api/user`、`getUserById`、`用户` |
| 模型 | 模型名、标题与模型本身的描述 | `UserResp`、`用户响应参数` |
| 附加文档 | 文档名、分组与正文 | 规范名称、正文中的关键词 |
| 方法组合 | 独立 HTTP 方法词与其他关键词 | `get 用户`、`post /api/user` |

多个空格分隔的关键词需要共同匹配，结果会优先展示名称与路径更直接的命中，并高亮相关片段。使用方向键选择结果、Enter 打开，Escape 关闭。

<Callout title="全局搜索与字段搜索" type="info">
全局搜索不遍历所有请求参数和模型属性描述，也不提供拼音转换搜索。查找某个字段时，先定位接口或模型，再使用页面内部的字段搜索；查找真实响应值时使用调试结果区的搜索。
</Callout>

网关搜索会逐步加载服务文档并构建索引。部分服务失败时会保留已成功的结果并提示加载情况；可以先限定当前可用服务，再判断是否需要检查未加载的节点。

## 从文档下载页选择范围

在“文档管理 → 文档下载”中选择接口范围，右侧同步提供导出前预览。预览基于接口规范生成，包括相关说明、字段、示例与请求资料。

| 单体范围 | 作用 |
| --- | --- |
| 全部接口 | 导出当前项目文档中的全部接口 |
| 按分组 | 选择业务分组中的接口集合 |
| 按接口 | 查找并勾选具体接口 |

网关模式支持“全部微服务”“按微服务选择”“跨服务细选”。导出当前需要的范围，比将整个集群全部内容交给每个接入方更便于阅读。

## 五种格式如何选

点击“导出文档”选择格式，检查摘要中的范围后再确认。

<ThemedScreenshot light="/images/screenshots/features/export-light.webp" dark="/images/screenshots/features/export-dark.webp" alt="文档导出格式选择窗口，提供 Word、PDF、Markdown、HTML 和 OpenAPI" width={660} height={359} />

| 格式 | 适合的用途 | 产物 / 行为 |
| --- | --- | --- |
| OpenAPI | 交给其他工具、生成客户端或归档契约 | `.json` 规范，保留所选接口需要的引用依赖 |
| Markdown | 放入代码仓库、继续编辑 | `.md` 文档 |
| HTML | 直接用浏览器阅读离线资料 | 独立 `.html` 文件 |
| Word | 交付、评审与二次编排 | `.docx` 文件 |
| PDF | 固定版式分发 | 打开浏览器打印窗口，选择另存为 PDF |

PDF 依赖浏览器的打印功能与弹窗设置。没有出现打印面板时，检查是否拦截了新窗口；当前不是服务端直接生成 PDF 文件。

## 导出的不只是接口路径

导出时会按选择范围组织接口说明，并收集需要的模型和相关规范引用，避免只留下路径却丢失依赖定义。

| 内容 | 作用 |
| --- | --- |
| 项目信息 | 标题、描述、文档版本与访问资料 |
| 参数与约束 | 参数位置、类型、必填、说明和枚举含义 |
| 请求与响应示例 | 命名示例或按 Schema 生成的示例 |
| 状态码与认证声明 | 对照成功、错误分支与需要的安全方案 |
| 关联模型 | 解释接口引用的数据结构 |
| 通用响应包装 | 适用时汇总公共结构，各接口保留自己的业务数据说明 |

导出示例来自规范与示例构造，不是把当前所有真实调试响应、Token、文件和流程运行结果打包成会话备份。

## 附加 Markdown 的导出是另一个入口

在“其他文档”阅读页中，可以导出当前说明为 Markdown、HTML、Word，或打印为 PDF。OpenAPI 规范不是 Markdown 文档的导出格式。

接口导出中心与附加文档阅读器各自处理自己的内容。需要同时交付两类资料时，分别检查和导出，不应假定选中接口就包含所有附加说明。

## 交付前检查

1. 确认当前服务、分组与接口勾选范围，核对已选数量。
2. 阅读预览中的主要接口、响应示例和字段约束。
3. 网关模式检查服务文档加载是否完整，处理未加载提示。
4. 根据交付用途选择格式；打印 PDF 时在系统面板确认纸张和版式。
5. 如果接口规范已经更新，重新加载当前服务文档并再次生成资料。
