接口详情把说明和结构放在同一工作区：主区域展示接口、认证要求与参数，示例区域提供请求和响应内容。先读清楚接口声明，再进入在线调试，可以减少把示例值当成业务规则的误解。

## 接口头部与快捷操作

| 内容 / 操作 | 用途 |
| --- | --- |
| 分组、接口名、operationId | 确认接口身份；operationId 支持复制 |
| HTTP 方法、服务基址、Path | 分别查看地址组成，复制路径或完整 URL |
| 接口说明 | 展示 OpenAPI 的摘要与详细描述 |
| 认证与 Sa-Token 信息 | 查看认证方案、权限、角色以及匿名标记 |
| 在线调试 | 将当前接口带入调试工作台 |
| AI 助手 | 复制当前接口信息，供外部助手或开发工具理解接口 |

“AI 助手”是接口资料的复制入口，当前界面不会在这里替你向某个大模型服务发送对话。

## 请求结构怎么看

参数按 Path、Query、Header、Cookie 与 Body 区分。字段类型之外，还会展示文档中已经声明的约束。

| 字段信息 | 示例 | 阅读方式 |
| --- | --- | --- |
| 类型与格式 | `integer (int64)`、`string (date-time)` | 用于判断传值类型与语义格式 |
| 必填 | `required` 标记 | 以当前参数或所属对象的声明为准 |
| 示例与默认值 | `example`、`default` | 示例用于理解；默认行为还要看宿主实现 |
| 范围 | 数值上下界、字符串长度 | 区分包含边界与不包含边界 |
| 正则 | `pattern` | 是接口契约的约束，不是自动修复输入的规则 |
| 枚举 | 候选值与含义 | 详见[参数填写与枚举](/guide/ui/parameters-enums) |
| 子结构 | 对象、数组元素、模型引用 | 展开查看嵌套字段，避免只看顶层包装对象 |

请求字段搜索与全局搜索是不同入口：详情中的“查找字段或描述”面向当前参数结构，适合在较大的对象中定位字段。

## 响应码、媒体类型与多个示例

响应说明按 HTTP 状态码组织。同一个状态码还可能声明多个媒体类型和多个命名示例，不能只看默认的第一项。

1. 选择状态码，确认成功与错误分支。
2. 如果存在多个 Content-Type，选择要了解的响应格式。
3. 如果存在命名示例，切换业务场景，查看各自的响应内容与说明。
4. 将“结构示例”与后端显式提供的示例区分开：结构示例由 Schema 推导，不是已经调用接口得到的结果。

例如单体 Demo 的“新增用户”同时声明 `200`、`400` 和 `409`；OpenAPI 多响应示例分组还覆盖同一状态码下的多个错误样例、默认响应码和没有正文的响应。

<Callout title="文档示例与实时响应" type="info">
接口详情中的示例用于说明接口契约；只有在线调试发起请求后的“实时响应”，才来自那次真实调用。业务错误码也可能放在 HTTP 200 的 JSON 正文中，需要同时阅读状态码和正文。
</Callout>

## 组合模型与示例阅读

当 Schema 使用 `oneOf` / `anyOf` 时，界面提供模型分支选择，查看不同分支的字段与示例；`allOf` 等结构参与模型解析。分支选择帮助理解当前视图，不能替代服务端对真实输入的验证。

JSON 示例支持对象与数组折叠、字段说明开关和复制。枚举字段可查看候选含义，长字符串可展开阅读。响应结构与请求结构分别保留自身语义，例如只读与只写字段应以所属方向的声明为准。

## 生成 TypeScript

请求和响应参数区域提供 TypeScript 生成入口。它适合把已经阅读过的接口结构带入前端项目：

- **请求参数**：将该接口的参数结构转换成 TypeScript 定义。
- **响应参数**：根据响应模型生成相应定义，检查所需状态码和类型。
- **复制之后**：按项目命名、请求库与业务约定整理，再交给 TypeScript 编译器验证。

生成的是类型资料，不包含业务请求封装，也不会自动与后端保持同步。接口 Schema 更新后应重新检查生成结果。

## 从实体模型反查结构

在左侧“实体模型”中选择模型，可以独立查看字段定义与 JSON 示例，并搜索模型字段或描述。常用于前端先了解 DTO、后端检查泛型包装、嵌套对象和枚举含义。

<ThemedScreenshot light="/images/screenshots/features/model-light.webp" dark="/images/screenshots/features/model-dark.webp" alt="UserResp 实体模型的字段定义与 JSON 示例" width={1120} height={830} />

模型页是文档视图，不是数据库表结构，也不是接口的实时数据。某个模型没有出现时，先检查它是否被当前 OpenAPI 文档收录，以及是否切换到了正确的分组或服务。

## 附加 Markdown 文档

“其他文档”用于阅读接入规范、错误码说明和变更记录等非接口内容。阅读页包含正文、标题目录、文件信息与导出入口。

| 想做的事 | 对应入口 |
| --- | --- |
| 阅读接口调用规范 | 左侧“其他文档”中的分组与文档 |
| 在一篇说明中跳转章节 | 阅读目录 |
| 带走当前说明 | 当前文档的导出按钮 |
| 加入自己的说明文件 | [Markdown 文档配置](/guide/config/markdownIntegrationConfiguration) |

附加文档和接口规范的导出入口各自独立，接口导出中心不等于把所有附加 Markdown 自动合成一本书。
