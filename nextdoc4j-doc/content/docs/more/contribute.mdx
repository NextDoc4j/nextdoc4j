## 分支模型

长期主线为 `master`，短期分支完成验证后提交 PR：

| 分支 | 用途 |
| --- | --- |
| `feat/<name>` | 新功能 |
| `fix/<name>` | 缺陷修复 |
| `docs/<name>` | 文档和官网 |
| `demo/<name>` | 集成示例 |

## 提交前检查

```bash
mvn test
(cd nextdoc4j-ui && pnpm check)
(cd nextdoc4j-doc && pnpm type-check && pnpm build)
```

提交内容请遵循 Angular Commit 规范，并同步更新相关文档和变更日志。
