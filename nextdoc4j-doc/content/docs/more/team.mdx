## 加入讨论群

讨论 Spring Boot / SpringDoc 接入、网关聚合和使用体验，可以先添加维护者微信，再由维护者邀请入群。

<CommunityContact />

需要定位具体问题时，建议附上版本、配置和复现步骤，便于大家一起排查。也可以在 [GitHub Discussions](https://github.com/NextDoc4j/nextdoc4j/discussions) 公开交流；可复现的缺陷和功能建议使用 [Issue 模板](https://github.com/NextDoc4j/nextdoc4j/issues/new/choose)记录，方便持续跟进。

## 赞助支持

如果 NextDoc4j 帮你节省了接入和联调时间，欢迎自愿支持项目维护。Star、反馈问题、补充文档和提交代码，同样是对项目的支持。
