## 什么是 NextDoc4j？

**NextDoc4j** 是一个基于现代 Web 技术栈深度重构的 Java API 文档与在线调试工作台。它专为 **SpringDoc** 和 **OpenAPI 3** 生态量身定制，旨在彻底打破传统 Swagger UI 陈旧、卡顿、交互不便的固有局限。

从 **1.4.0 版本** 起，NextDoc4j 实现了**单套 Starter 坐标**对 **Spring Boot 3.4.x** 与 **Spring Boot 4.x** 的无缝统一支持，并在单体 WebMvc / WebFlux 与 Spring Cloud Gateway 微服务网关场景中提供全功能开箱即用能力。
